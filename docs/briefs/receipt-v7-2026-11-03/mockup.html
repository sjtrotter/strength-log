Receipt v7

v6 with every finding from the Material 3 audit applied. The layout is unchanged: name on top, the work under it, chevron and PR label on the right.

  • Theme roles only. Type uses the app's roles (session name in displaySmall, numbers in headlineSmall, old bests in titleMedium, PR labels in labelMedium), and every color comes from the theme.
  • Contrast. PR labels use a new container rule (15% day color on dark, 10% on light) that clears 4.5:1 on all seven days in both themes. The snackbar is the stock one.
  • Not color alone. The rep that set a record is underlined as well as colored.
  • At most three lines per row. Two weights get a line each; three or more show the heaviest set and "and 2 lighter sets".
  • TalkBack. Every row has a spoken version (table below); rows that open announce expanded or collapsed.
  • New: light-theme frames, a full 200% font frame, the note-sheet failure, and rules for a missing top set, a blank distance and two records on one row.

Screen states

Behavior the build follows

  • Finishing. Done is disabled until Finish has saved, so leaving can never cut a save short. Back waits too. TalkBack hears "Finishing workout" once. Placeholder bars appear only after 260 ms, the app's existing delay.
  • Finish failed. The day is not marked done and the plan does not move on. Try again repeats Finish and is ignored while a try is running. Back, and Back to workout, return to the last set. Nothing on this screen counts as Done.
  • Receipt open. Back means Done, as today. Records roll in once per receipt, never again after rotation or reopening, and not at all with reduced motion on.
  • Note not saved. The sheet stays open with your text, and a snackbar above it offers Try again. The snackbar stays until you act or close the sheet.
  • Records not checked. If the old bests can't be read, the receipt still shows and says so in one gray line. It never shows zero records as if that were the result.

Departures from Material, recorded in KDoc

  • Rows open and close. Material has no expandable list item. It is built from ListItem plus AnimatedVisibility, with expanded/collapsed state in semantics.
  • PR label. A non-interactive tonal Surface with words. Material's Badge holds counts and chips are interactive. This is also the one exception to DESIGN.md's "no badges".
  • Placeholder bars while finishing. Material has no skeleton component. The receipt already knows the exercise names, so bars in place of the numbers keep the layout from jumping. #447 decides whether other screens adopt them.
  • Work figures larger than ListItem's supporting text (headlineSmall instead of bodyMedium). The numbers are the receipt's content.
