**The overview needs names.** Six anonymous dots convey quantity and location, but cannot tell someone whether leg curl or pull-up is finished. **Gestures need clear boundaries.** Pager touch slop distinguishes ordinary taps from drags, and its default fling snaps to a page. Standard click handling cancels a press when the pager consumes the drag; this is useful protection, not proof against accidental input. Keep checkbox targets at least 48 dp, with separate value-edit targets. Put the rest pill outside the pager and steppers in the modal sheet, whose scrim blocks background interaction. No sliders, swipe-to-delete, horizontal value adjustment or competing horizontal recognizers inside a page. Supply previous/next buttons and the named overview for people who cannot swipe. Logging callbacks target the displayed set’s stable identity and disable while its write is pending; a drag or page change must never log a different set.

**Compose is the boundary.** Use Scaffold, a fixed TopAppBar, HorizontalPager and ordinary Column/Row/Surface compositions. `rememberPagerState(pageCount = { exercises.size })` owns saveable pager position. Supply `key = { exercises[it].instanceId }`, `beyondViewportPageCount = 1`, and `PagerDefaults.flingBehavior(state = pagerState)`. Use `contentPadding = PaddingValues(0.dp)`: a next-card peek would steal width from references and imply an actionable sliver. The named next control supplies discovery instead. A’s completion body can use AnimatedContent inside the fixed page; it must not resize the pager or dock.

The day indicator is a plain Row of Boxes with fill/border states and a spoken summary, following the construction in Google’s “Pager in Compose.” A LinearProgressIndicator could show completed/total, but would lose per-exercise positions. If exercise-name tabs replace the segments, use PrimaryScrollableTabRow with `selectedTabIndex = pagerState.currentPage`, Tab, and `rememberCoroutineScope().launch { pagerState.animateScrollToPage(index) }`. This alternative sits above the pager. Existing day tabs select program days separately. Editors use ModalBottomSheet, IconButton, OutlinedTextField and Button; overview and set sheets use keyed LazyColumn items. HTML interactions simulate these library controls; they are not proposed Android widgets. Google titles “Pager in Compose,” “Tabs,” “State and Jetpack Compose,” “Save UI state in Compose,” and “Accessibility in Compose” are recalled from memory, not fetched or version-verified.

**A page is not a workout mutation.** DayViewModel already routes ticks and valid edits through repository writes; keep that path and TOP cascading. Never wait for a swipe, sheet dismissal or Finish to save a set. Save the deliberately selected exercise ID per day/session in SavedStateHandle, observing pager `settledPage` through snapshotFlow in LaunchedEffect. Reconcile that ID after insertion or removal; the saveable numerical position alone is insufficient. Without a valid restored selection, derive the first unfinished exercise. Derive B’s current set from persisted completion flags; save the editor’s set ID and draft separately. Rest remains deadline-based. Pager eviction cannot own or erase workout data, and saved UI state is not a substitute for database durability.

**The watch can share vocabulary without changing gestures.** B’s day segments correspond to the overview’s exercise ring; its set segments correspond to the workout’s round ring. The focused prescription and primary completion action correspond to the disc. Left means next exercise in both. The equivalence stops there: the native phone pager moves right to the previous exercise and stops at its ends; the watch wraps left and reserves right for overview. The watch also restricts left-swiping to READY/REST_OVER, and its READY disc starts lifting before logging. The phone keeps immediate ticking and can browse during rest. No infinite pager or custom gesture emulation is proposed. A offers the watch little beyond consistent completion and set-count language. I would change nothing on the watch in this round.
